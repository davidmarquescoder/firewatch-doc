Legenda das colunas: **PK** chave primária, **FK** chave estrangeira, **UK** índice único, **IDX** índice simples. "Cast" é a conversão feita pelo modelo Eloquent.

## Domínio

### `connectors`

Integrações externas. Modelo `App\Models\Connector\Connector`.

| Coluna | Tipo | Detalhes |
|---|---|---|
| `id` | uuid | PK |
| `type` | string | Cast `ConnectorTypeEnum` |
| `name` | string | UK |
| `credentials` | text, nulo | Cast **`encrypted:array`**. Oculto na serialização (`#[Hidden]`) e fora da auditoria |
| `settings` | json, nulo | Configurações não secretas (`workspace`, `channel`, `base_url`, `project_key`…), validadas por `ConnectorTypeEnum::settingsRules()` |
| `status` | string | Padrão `active`. Cast `ConnectorStatusEnum` |
| `last_error` | text, nulo | Mensagem do último teste de conexão que falhou |
| `last_verified_at` | timestamp, nulo | Último teste de conexão |
| `created_at`, `updated_at`, `deleted_at` | timestamp | Soft delete |

**Índices:** `name` (único), `(type, status)`.

**Relacionamentos:** `applications()` → `hasMany(Application)` pela coluna `repository_connector_id`; `issueTrackerApplications()` → `hasMany(Application)` pela coluna `issue_tracker_connector_id` (Jira). `isInUse()` olha as duas. Conectores de Slack não têm relação: as notificações vão para **todos os conectores ativos** do tipo.

### `applications`

Sistemas monitorados. Modelo `App\Models\Application\Application`.

| Coluna | Tipo | Detalhes |
|---|---|---|
| `id` | uuid | PK |
| `name` | string | UK |
| `monitoring_identifier` | string | UK. Como a aplicação aparece no Sentry ou no webhook |
| `repository_connector_id` | uuid, nulo | FK → `connectors.id`, `ON DELETE SET NULL` |
| `issue_tracker_connector_id` | uuid, nulo | FK → `connectors.id`, `ON DELETE SET NULL`. Conector Jira onde o card do incidente é criado. Nulo = qualquer Jira ativo |
| `repository_slug` | string, nulo | `workspace/repo`. Obrigatório quando há conector |
| `base_branch` | string | Padrão `main`. Não pode começar com `firewatch/` |
| `runner_image` | string | Padrão `firewatch-runner:latest` |
| `install_command`, `test_command` | text, nulo | Vazio = `auto` |
| `trigger_rules` | json, nulo | Mesclado com `DEFAULT_TRIGGER_RULES` por `resolvedTriggerRules()` |
| `active` | boolean | Padrão `true` |
| `created_at`, `updated_at`, `deleted_at` | timestamp | Soft delete |

**Índices:** `name` e `monitoring_identifier` (únicos).

**Relacionamentos:** `repositoryConnector()` → `belongsTo(Connector)`; `incidents()` → `hasMany(Incident)`.

Regras padrão de acionamento (`Application::DEFAULT_TRIGGER_RULES`):

```json
{
  "enabled": true,
  "min_severity": "error",
  "min_occurrences": 1,
  "min_affected_users": 0,
  "environments": ["production"],
  "ignore_patterns": []
}
```

### `incidents`

Erros únicos de uma aplicação. Modelo `App\Models\Incident\Incident`.

| Coluna | Tipo | Detalhes |
|---|---|---|
| `id` | uuid | PK. A referência curta (`inc-xxxxxxxx`) usa os últimos 8 caracteres |
| `application_id` | uuid | FK → `applications.id`, `ON DELETE RESTRICT` |
| `fingerprint` | string | Chave de deduplicação dentro da aplicação (ex.: `sentry:<issue id>`) |
| `title` | string(512) | |
| `environment` | string, nulo | `production`, `staging`… |
| `raw_payload` | longText, nulo | Payload original, cast **`encrypted:array`**, oculto na serialização. Nunca vai para o modelo nem para o painel |
| `sanitized_payload` | json, nulo | Evento normalizado com dados sensíveis mascarados. O único payload exibido ou enviado ao Claude |
| `severity` | string | Padrão `error`. Cast `IncidentSeverityEnum` |
| `occurrences` | unsigned int | Padrão 1. Somado a cada evento deduplicado |
| `affected_users` | unsigned int | Padrão 0. Guarda o maior valor recebido |
| `status` | string | Padrão `received`. Cast `IncidentStatusEnum` |
| `status_reason` | text, nulo | Motivo legível do status atual (trigger, fila, falha) |
| `failure_kind` | string, nulo | Cast `IncidentFailureKindEnum`. Preenchido só em `failed` |
| `pr_url` | string, nulo | Link do Pull Request |
| `jira_key` | string, nulo | Chave do card (ex.: `OPS-123`) |
| `first_seen_at`, `last_seen_at` | timestamp, nulo | Primeira e última ocorrência |
| `received_at`, `ignored_at`, `queued_at`, `investigating_at`, `fixing_at`, `testing_at`, `pr_opened_at`, `failed_at` | timestamp, nulo | **Uma coluna por status**: gravada por `transitionTo()` quando o incidente chega nele (`<status>_at`) |
| `created_at`, `updated_at`, `deleted_at` | timestamp | Soft delete |

**Índices:** `(application_id, fingerprint)`, `status`, `failure_kind`.

**Relacionamentos:** `application()` → `belongsTo(Application)`; `agentRuns()` → `hasMany(AgentRun)`; `latestAgentRun()` → `hasOne(AgentRun)->latestOfMany()`.

**Eventos do modelo:** ao criar, preenche `received_at`, `first_seen_at` e `last_seen_at`; ao criar e a cada mudança de `status`, transmite `IncidentStatusChanged` pelo Reverb.

### `agent_runs`

Uma execução do time de agentes. Modelo `App\Models\AgentRun\AgentRun` (sem soft delete: histórico).

| Coluna | Tipo | Detalhes |
|---|---|---|
| `id` | uuid | PK. Também nomeia o container (`firewatch-run-<id>`) |
| `incident_id` | uuid | FK → `incidents.id`, `ON DELETE CASCADE` |
| `status` | string | Padrão `pending`. Cast `AgentRunStatusEnum` |
| `exit_code` | smallint, nulo | Código de saída do runner |
| `failure_stage` | string, nulo | Etapa em que falhou (`clone`, `install`, `claude`, `flow`, `verify`…) |
| `failure_reason` | text, nulo | Explicação para o time (do `FailureClassifier`) ou motivo bruto do runner |
| `work_branch` | string, nulo | `firewatch/<chave>-<descrição>` |
| `model` | string, nulo | Modelo do Claude usado |
| `session_id` | string, nulo | Sessão do Claude Code |
| `started_at`, `finished_at` | timestamp, nulo | |
| `duration_seconds` | unsigned int, nulo | |
| `input_tokens`, `output_tokens` | unsigned bigint | Padrão 0 |
| `cost_usd` | decimal(10,4), nulo | Custo real informado pelo Claude Code. Soma do mês = gasto do budget |
| `budget_usd` | decimal(10,4), nulo | Teto passado ao Claude Code nesta execução |
| `num_turns` | unsigned int, nulo | |
| `report` | json, nulo | Relatório final completo (schema v1). Credenciais embutidas na URL do repositório (`git.repository`) são removidas antes de gravar |
| `team` | json, nulo | Cópia dos perfis de agentes no início da execução |
| `created_at`, `updated_at` | timestamp | |

**Índices:** `(incident_id, created_at)`, `status`.

**Relacionamentos:** `incident()` → `belongsTo(Incident)`; `events()` → `hasMany(AgentEvent)`, ordenado por `sequence`.

**Ciclo:** `markRunning()` (`pending` → `running`, grava `started_at`, `work_branch` e `team`) e `finishWithReport()` (copia os campos do relatório para as colunas, registra a auditoria e confere os alertas de budget). As duas lançam `LogicException` se chamadas fora de ordem.

### `agent_events`

Cada passo registrado de uma execução. Modelo `App\Models\AgentEvent\AgentEvent`. Só tem `created_at` (sem `updated_at` nem soft delete): eventos não mudam.

| Coluna | Tipo | Detalhes |
|---|---|---|
| `id` | uuid | PK |
| `agent_run_id` | uuid | FK → `agent_runs.id`, `ON DELETE CASCADE` |
| `sequence` | unsigned int | Ordem do evento na execução (`nextSequenceFor()`) |
| `agent` | string | Slug do subagente, ou `chefe-de-plantao`, `runner` ou `firewatch` |
| `type` | string | Cast `AgentEventTypeEnum` |
| `content` | mediumText, nulo | Texto do evento, cortado em 65.535 caracteres |
| `metadata` | json, nulo | Ferramenta, comando, arquivo, resultado de testes, integração… |
| `tool_use_id` | string, nulo | Liga a chamada de ferramenta ao seu resultado |
| `occurred_at` | timestamp(3) | Momento do evento, com milissegundos |
| `created_at` | timestamp, nulo | |

**Índices:** `(agent_run_id, sequence)` **único**, `(agent_run_id, tool_use_id)`.

**Relacionamentos:** `agentRun()` → `belongsTo(AgentRun)`. Ao criar, transmite `AgentEventRecorded` no canal do incidente.

### `agent_profiles`

O time de agentes, editável pelo painel. Modelo `App\Models\AgentProfile\AgentProfile`.

| Coluna | Tipo | Detalhes |
|---|---|---|
| `id` | uuid | PK |
| `slug` | string | UK. Kebab-case (`advogado-do-diabo`). É o nome do subagente no Claude Code |
| `name` | string | Nome exibido |
| `role` | string | Cast `AgentRoleEnum` |
| `description` | text | Quando o orquestrador deve chamar este agente |
| `avatar` | string, nulo | |
| `system_prompt` | longText | |
| `allowed_tools` | json, nulo | Subconjunto de `Read`, `Grep`, `Glob`, `Bash`, `Edit`, `Write`, `NotebookEdit`, `Agent`, `TodoWrite` |
| `command_access` | string | Padrão `none`. Cast `AgentCommandAccessEnum` |
| `write_access` | string | Padrão `none`. Cast `AgentWriteAccessEnum` |
| `model` | string, nulo | Modelo específico do agente. Vazio = o da execução |
| `active` | boolean | Padrão `true` |
| `sort_order` | unsigned smallint | Padrão 0 |
| `created_at`, `updated_at`, `deleted_at` | timestamp | Soft delete |

**Índices:** `slug` (único), `(active, sort_order)`.

**Métodos de consulta:** `orchestrator()` (o perfil com papel `orchestrator`) e `activeSubagents()`. Conversões para o runner: `toAgentDefinition()` (entrada do `agents.json`), `toToolPolicy()` (entrada do `policy.json`) e `toTeamSnapshot()` (cópia para `agent_runs.team`).

### `app_settings`

Configurações globais editadas pelo painel, em formato chave/valor. Modelo `App\Models\AppSetting\AppSetting`, com `AppSetting::read($key)` e `AppSetting::write($key, $value)`.

| Coluna | Tipo | Detalhes |
|---|---|---|
| `id` | uuid | PK |
| `key` | string | UK |
| `value` | json, nulo | Cast `array` |
| `created_at`, `updated_at` | timestamp | |

| Chave | Valor | Escrita por |
|---|---|---|
| `budget` | `{ per_run_usd, monthly_usd, alert_percent }` | Tela **Custos e limites** (auditada) |

## Infraestrutura

### `notifications`

Notificações do Laravel no banco (canal `database`).

| Coluna | Tipo | Detalhes |
|---|---|---|
| `id` | uuid | PK |
| `type` | string | Classe da notificação |
| `notifiable_type`, `notifiable_id` | string, **unsigned bigint** | Morph (`morphs`), com índice composto |
| `data` | text | JSON da notificação |
| `read_at` | timestamp, nulo | |
| `created_at`, `updated_at` | timestamp | |

::warning
A coluna `notifiable_id` é **bigint**, mas os usuários têm id **UUID**. Uma notificação de banco para um `User` falharia ao gravar. Hoje o FireWatch não usa o canal `database` (os alertas vão para o Slack), então a tabela fica vazia. Para usá-la, troque `morphs` por `uuidMorphs` numa migration nova. O mesmo vale para `personal_access_tokens.tokenable_id` (tokens do Sanctum), que não é usado porque o painel autentica por sessão.
::

### `activity_log`

Trilha de auditoria do `spatie/laravel-activitylog`, lida pela tela **Auditoria** do painel.

| Coluna | Tipo | Detalhes |
|---|---|---|
| `id` | bigint | PK, auto incremento |
| `log_name` | string, nulo | IDX. Categoria (`AuditLogEnum`) |
| `description` | text | O que aconteceu |
| `subject_type`, `subject_id` | string, uuid, nulo | O registro afetado (`nullableUuidMorphs`) |
| `event` | string, nulo | `created`, `updated`, `deleted` ou ação própria |
| `causer_type`, `causer_id` | string, uuid, nulo | Quem fez (usuário); nulo para ações do sistema |
| `attribute_changes` | json, nulo | Valores antigos e novos |
| `properties` | json, nulo | Dados extras (já mascarados) |
| `created_at`, `updated_at` | timestamp | |

| `log_name` | Rótulo | O que registra | Modelos |
|---|---|---|---|
| `configuration` | Configuração | Quem mudou o quê | `Connector` (sem `credentials`), `Application`, `AgentProfile`, `AppSetting`, `Organization`, `User` (só nome, e-mail, ativo e troca de senha) |
| `incident` | Incidentes | Ciclo de vida | `Incident` (status, motivo, kind, severidade, PR, Jira) e `AgentRun` (status, exit code, falha, custo) |
| `action` | Ações manuais | Teste de conector, simular, reexecutar | Registrado pelo `AuditLogger` |
| `agent` | Agentes | O que os agentes fizeram em cada execução (ferramentas, tentativas bloqueadas, arquivos) | Registrado no `finishWithReport()` |

A limpeza roda todo dia às 03:30 (`activitylog:clean`) e apaga registros com mais de **365 dias** (`activitylog.clean_after_days`).

### `permissions` e tabelas do Spatie

Papéis e permissões do `spatie/laravel-permission`. As chaves de `roles` e `permissions` são **bigint**; as colunas `model_id` das tabelas de vínculo são **uuid**, para casar com `users.id`.

| Tabela | Colunas | Chaves |
|---|---|---|
| `permissions` | `id`, `name`, `guard_name`, timestamps | UK `(name, guard_name)` |
| `roles` | `id`, `name`, `guard_name`, timestamps | UK `(name, guard_name)` |
| `model_has_permissions` | `permission_id`, `model_type`, `model_id` (uuid) | PK composta; FK → `permissions` `CASCADE` |
| `model_has_roles` | `role_id`, `model_type`, `model_id` (uuid) | PK composta; FK → `roles` `CASCADE` |
| `role_has_permissions` | `permission_id`, `role_id` | PK composta; FKs `CASCADE` |

Dados criados pelos seeders:

| Papel (`RoleEnum`) | Rótulo | Permissões (`PermissionEnum`) |
|---|---|---|
| `developer` | Desenvolvedor | Todas: `view`, `create`, `edit`, `delete` |
| `admin` | Administrador | As genéricas: `view`, `create`, `edit`, `delete` |

### Tabelas do framework

| Tabela | Para quê | Usada hoje? |
|---|---|---|
| `sessions` | Sessões em banco | Não: `SESSION_DRIVER=redis` |
| `password_reset_tokens` | Recuperação de senha | Não: o projeto não tem rota de recuperação de senha |
| `cache`, `cache_locks` | Cache e locks em banco | Não: `CACHE_STORE=redis` |
| `jobs`, `job_batches` | Fila em banco | Não: filas no Redis |
| `failed_jobs` | Jobs que falharam | Sim: falhas das filas Redis também caem aqui |
| `personal_access_tokens` | Tokens do Sanctum | Não: o painel usa sessão por cookie |
