Uma rota só alimenta a tela **Visão geral**. Como cada número é calculado e onde as contas surpreendem está em [Métricas](/conectores-aplicacoes-budget-e-metricas/metricas). Controller: `MetricsController`; cálculo: `IncidentMetrics::overview()`.

| Método | Rota | O que faz |
|---|---|---|
| `GET` | `/api/v1/metrics/overview` | Resumo do período atual e do anterior, números de agora, série diária, top aplicações e motivos de falha |

## Ver o overview

```http
GET /api/v1/metrics/overview
```

| | |
|---|---|
| **Permissão** | Qualquer usuário logado |
| **Sucesso** | `200` |

### Request

Parâmetros de query, todos opcionais:

| Campo | Tipo | Obrigatório | Regras |
|---|---|---|---|
| `days` | inteiro | Não | `7`, `30` ou `90` (`MetricsController::PERIODS`). Padrão `7` |
| `timezone` | string | Não | Fuso IANA válido (`timezone:all`), como `America/Sao_Paulo`. Padrão: `APP_TIMEZONE` |

O fuso define a meia-noite que abre o período e os dias da série `daily` ([O período](/conectores-aplicacoes-budget-e-metricas/metricas#o-período)).

### Response

`data` tem seis blocos. O significado de cada campo está em [A resposta](/conectores-aplicacoes-budget-e-metricas/metricas#a-resposta).

| Bloco | Tipo | Campos |
|---|---|---|
| `period` | objeto | `days`, `from`, `to` (ISO 8601 no fuso pedido), `timezone` |
| `live` | objeto | `active`, `waiting` |
| `current`, `previous` | objeto | `incidents`, `prs_opened`, `failed`, `ignored`, `success_rate`, `avg_time_to_pr_seconds`, `median_time_to_pr_seconds`, `fastest_time_to_pr_seconds`, `cost_usd` |
| `daily` | lista | Um item por dia: `date`, `incidents`, `prs_opened`, `failed`, `other`, `median_time_to_pr_seconds` |
| `applications` | lista | Até 5: `id`, `name`, `incidents`, `prs_opened` |
| `failure_kinds` | lista | `kind`, `label`, `incidents` |

`success_rate` e os tempos até o PR são `null` quando não há base para a conta.

### Erros

| Status | Quando | Mensagem |
|---|---|---|
| `422` | `days` fora de 7, 30 e 90 | "O campo days selecionado é inválido." |
| `422` | `timezone` inválido | "O campo timezone deve ser uma zona válida." |
