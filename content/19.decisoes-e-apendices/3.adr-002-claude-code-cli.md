## Contexto

O time de agentes precisa de muito mais que um modelo respondendo texto:

- **ferramentas** para ler e editar arquivos, procurar no código e rodar comandos (testes, `git log`, `git blame`);
- **subagentes** com papéis, prompts e ferramentas próprios (Sentinela, Detetive, Advogado do Diabo, Cirurgião, Escrivão), chamados por um orquestrador;
- um **limite de gasto** por execução;
- um jeito de **restringir** o que cada agente faz, por papel;
- um **fluxo de eventos** em tempo real, para a timeline ao vivo do painel.

Escrever tudo isso sobre a API do Claude é um projeto em si: o loop de ferramentas, a edição segura de arquivos, a gestão de contexto em sessões longas, a delegação entre agentes. O MVP precisava funcionar de ponta a ponta numa demonstração.

## Decisão

**Os agentes rodam no Claude Code, a CLI da Anthropic, em modo headless**, dentro do runner:

```bash
claude -p "$PROMPT" --output-format stream-json --verbose \
  --forward-subagent-text --permission-mode bypassPermissions \
  --max-budget-usd … --agents /runner/input/agents.json \
  --append-system-prompt-file /runner/input/system-prompt.md --settings <hook da guarda>
```

| Necessidade | O que o Claude Code dá |
|---|---|
| Ferramentas | `Read`, `Grep`, `Glob`, `Edit`, `Write`, `Bash`, prontas |
| Subagentes | `--agents` com um JSON por agente: o Laravel converte os perfis do banco nesse arquivo a cada execução ([Perfis de agente](/perfis-de-agente)) |
| Limite de gasto | `--max-budget-usd` |
| Restrição por papel | Hook `PreToolUse` que a guarda de ferramentas aplica mesmo com `bypassPermissions` ([Guarda de ferramentas](/runner/tool-guard)) |
| Tempo real | `--output-format stream-json`: uma linha JSON por evento, com `parent_tool_use_id` para saber qual subagente falou |
| Custo e tokens | O evento `result` traz `total_cost_usd`, tokens e turnos |

Credencial: uma chave da API (`ANTHROPIC_API_KEY`) ou um token da assinatura (`CLAUDE_CODE_OAUTH_TOKEN`, gerado com `claude setup-token`).

## Alternativas

| Opção | O que mudaria |
|---|---|
| Loop próprio sobre a API do Claude (Messages API com *tool use*) | Controle total sobre cada chamada e sobre o formato dos eventos, sem depender de uma CLI. Em troca, o Firewatch teria de implementar e manter as ferramentas, a edição de arquivos, a delegação entre agentes e a gestão de contexto |
| Claude Agent SDK | Os mesmos recursos do Claude Code como biblioteca, chamados por código. Exigiria um processo em Python ou TypeScript dentro do runner fazendo o papel do `entrypoint.sh`, com o mesmo resultado |
| Outro framework de agentes | Uma camada a mais entre o Firewatch e o modelo, com outro formato de eventos e outra forma de restringir ferramentas |

## Consequências

**A favor:**

- O time de agentes inteiro é **configuração**: prompts, ferramentas e níveis de acesso vêm do banco e viram arquivos, sem código novo para um agente novo.
- O runner é testável sem gastar créditos: um `fake-claude` imita a CLI, e uma API falsa permite rodar o Claude Code real sem chamar a Anthropic ([Sem Claude de verdade](/testes-e-qualidade/sem-claude-de-verdade)).
- Melhorias do Claude Code (ferramentas, contexto, modelos) chegam ao Firewatch ao reconstruir a imagem.

**Contra:**

- **O formato do `stream-json` é um contrato de outra pessoa.** O `StreamEventMapper` depende dos tipos de evento, do `parent_tool_use_id` e do `result`. Uma versão nova do Claude Code que mude esse formato quebra a timeline e a contagem de custo, sem erro de compilação.
- **A versão não está fixada.** O `Dockerfile` do runner instala `@anthropic-ai/claude-code@latest` (`CLAUDE_CODE_VERSION`). Reconstruir a imagem pode trazer uma versão com outro comportamento. Para builds reproduzíveis, passe uma versão no build arg e teste com o incidente-001 antes de subir ([Caso de referência](/operacao/caso-de-referencia)).
- **`bypassPermissions` é obrigatório** num processo sem ninguém para aprovar. A contenção vem da guarda de ferramentas, do container e da rede, não das permissões da CLI.
- O Claude Code faz chamadas próprias (atualização, telemetria); o runner as desliga com `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1`, e a rede só deixa passar a API da Anthropic.
- O custo depende de quantas vezes os subagentes releem o código: o caso de 12/11 pelo painel, com o time completo, custou cerca de cinco vezes o do terminal, com um agente só.
